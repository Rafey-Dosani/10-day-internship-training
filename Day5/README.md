# Day 5 — JavaScript & Employee Dashboard

## Objective

Practice modern JavaScript, asynchronous programming, and REST APIs.

## JavaScript Practice

* JavaScript fundamentals
* Array methods
* Promises and async/await
* Error handling
* Modules
* Fetch API

## Employee Dashboard

A JavaScript-based employee management dashboard using the JSONPlaceholder REST API.

### Features

* List employees
* Search employees
* Filter by department
* Sort employees
* View employee details
* Add employees
* Edit employees
* Delete employees

## Technologies

* HTML
* CSS
* JavaScript
* REST API
* Fetch API

## Run

Open `employee-dashboard/index.html` in a browser or use VS Code Live Server.
