## 👨‍💼 Employee Management System

A menu-driven Python application supporting:

* Add Employee
* Update Employee
* Delete Employee
* Search Employee
* List Employees
* Filter by Department
* Sort by Salary
* Statistics

### Technologies

* Python
* JSON
* Exception Handling
* Object-Oriented Programming

Data is stored persistently in `employees.json`.

Run:

```bash
cd management-system
python main.py
```

## 📊 CSV Data Analysis

Analyzes a CSV dataset and reports:

* Total record count
* Missing values
* Duplicate records
* Average values
* Minimum and maximum values
* Department-wise statistics

Uses Python's built-in `csv` module.

Run:

```bash
cd csv-analysis
python analyze_csv.py
```
